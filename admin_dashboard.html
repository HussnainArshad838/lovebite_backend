✅ How it works:
1. Select a device from the dropdown above
2. Click Front Camera or Back Camera button
3. Mobile device will request camera permission
4. Live video feed will appear in the video area
5. Use Stop Camera to end the session
⚠️ Troubleshooting:
• Make sure mobile device is online and LoveBite app is running
• Check that camera permission is granted on mobile device
• Ensure WebSocket connection is established (green status above)
• Try refreshing the page if video doesn't appear
